## 三、日常：怎么确认备份在正常运行
1. 打开 Finder → 桌面 → 百度同步盘 → 伴月轩AI系统开发 → 线上备份，看有没有**当天或昨天日期**的两个 `.enc` 文件。
2. 看运行日志：终端运行 `tail -20 ~/Library/Logs/banyuexuan-offsite-backup.log`。
3. 想立刻手动备份一次：终端运行 `bash ~/.banyuexuan/offsite-backup-pull.sh`。
4. 电脑如果长时间没开机，备份就会断；开机后会自动补一次，或手动运行上面第 3 条。

## 四、怎么用备份（恢复）

### A. 只想看看备份里有什么（不影响线上）
```bash
cd ~/Desktop/百度同步盘/伴月轩AI系统开发/线上备份
openssl enc -d -aes-256-cbc -pbkdf2 -in banyuexuan_prod-日期.sql.gz.enc -pass file:$HOME/.banyuexuan-backup-pass | gunzip > ~/Desktop/restore.sql
```
得到 `restore.sql`（普通 SQL 文本）。把“日期”换成文件夹里真实的文件名。

### B. 线上数据被误删/改坏，要还原数据库
1. **先别慌，先备份现状**：登录服务器运行 `cd ~/banyuexuan && sudo bash scripts/backup-mysql.sh`。
2. 按 A 解密得到 `restore.sql`，传到服务器：`scp -i ~/Desktop/百度同步盘/"AI 密匙"/fanqieai1004.pem ~/Desktop/restore.sql ubuntu@fanqieai.cc:~/restore.sql`。
3. 登录服务器，还原（会覆盖现有数据，确认后再做）：
```bash
sudo docker exec -i banyuexuan-prod-mysql-1 sh -c 'mysql -uroot -p"$MYSQL_ROOT_PASSWORD" banyuexuan_prod' < ~/restore.sql
```
4. 还原后用网页登录检查数据，必要时让 AI 助手帮你核对。
> 误删的客户通常在“回收站”里还能找回（保留 30 天），不一定要还原整个数据库。

### C. 还原上传的文件（合同原件、护理照片）
```bash
openssl enc -d -aes-256-cbc -pbkdf2 -in files-日期.tar.gz.enc -pass file:$HOME/.banyuexuan-backup-pass > ~/Desktop/files.tar.gz
```
再传到服务器，在服务器上：`sudo docker cp files.tar.gz banyuexuan-prod-api-1:/tmp/ && sudo docker exec banyuexuan-prod-api-1 tar xzf /tmp/files.tar.gz -C /repo/apps/api`。

### D. 服务器彻底坏了/换新服务器
1. 买/重置一台 Ubuntu 服务器，装好 Docker，开放 80/443 端口，把域名解析到新 IP。
2. `git clone git@github.com:Alston3825/banyuexuan-monorepo.git ~/banyuexuan`。
3. 把 `~/伴月轩备份-密钥/env.prod.latest` 传到服务器，改名为 `~/banyuexuan/.env.prod`，`chmod 600`。
4. `cd ~/banyuexuan && sudo bash scripts/deploy.sh`（自动建库、建表、启动）。
5. 按 B 还原数据库，按 C 还原文件。
这一套比较专业，**建议让 AI 助手（Claude 或别的）照着本文件和 `docs/交接手册.md` 一步步帮你做**。

### E. Claude 用不了，换别的 AI 接着开发
1. 让新的 AI 打开 GitHub 仓库 `git@github.com:Alston3825/banyuexuan-monorepo.git`（需要你的 GitHub 授权/SSH 权限）。
2. 对它说：“请先阅读仓库里的 `docs/交接手册.md`、`AGENTS.md`、`docs/进度快照.md`、`docs/待完善清单.md`、`docs/备份使用说明.md`，然后按里面的约定继续开发。我不懂编程，请用中文、讲人话。只有我说‘上线’才能部署。”
3. 需要它上线时，告诉它服务器私钥在 `~/Desktop/百度同步盘/AI 密匙/fanqieai1004.pem`。

## 五、安全提醒
- **绝对不要**把 `.env.prod`、加密口令、私钥文件发到聊天里、微信里或放进 GitHub。
- 如果怀疑密钥泄露：到对应平台重置（火山引擎、快递100、腾讯云密钥），再更新服务器 `.env.prod` 并重启。以前聊天里出现过的火山引擎按量 key 和快递100 key，建议你现在就去重置。
- 数据库备份里有客户个人信息，所以只放加密文件，且不放 GitHub。
