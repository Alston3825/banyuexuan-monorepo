# 伴月轩月子中心AI系统 · 设计语言

> 用户 2026-11-13 提供，是本系统（后台页面、插画、封面、海报、图标等）今后统一采用的设计哲学。写新页面/改页面/做配图前先读这份。
> 落地到后台业务页面时，仍须同时遵守 CLAUDE.md 的“界面开发规范”（搜索、手机卡片、弹窗等）——两者冲突时，业务可用性优先，视觉层面按本文件。

请按下面这套设计语言完成需求。它适用于任何载体：插画、封面、海报、网页、App 界面、图标、PPT、信息图、摄影和动效。先理解原则，再按载体套用规则。

## 一、整体气质

像一位有人文底色的科学工作者，博学而克制，聪明但不端庄。画面朴素、安静、温暖，有明显的人的痕迹，不追求科技感和炫目感。整体像一份研究机构发布的报告，或一本书里的一页，而不是营销海报、科技发布会或商业模板。

## 二、两种视觉语言，按需求选一种

**A. 手绘线条（默认）**：纯色底，加粗马克笔画的墨线和米白色块，画一个日常物件和一个动作，常常有一只手在和物件互动。适合文章配图、封面、产品功能说明、图标和轻量的网页插画。

**B. 研究档案拼贴**：把旧照片、手写笔记本纸、地形图、刻度尺、网格纸、科学仪器和自然风景拼贴在一起，再叠上几块纯色几何形状（例如带网格线的半圆、矩形）。像实验室档案和博物馆藏品，有纸张、墨迹和印刷的质感。适合品牌主视觉、研究报告、长文头图和官网首屏。

两种语言可以出现在同一个网站的不同部分，但一个画面只用一种。

## 三、五条原则

1. **减法**：每个画面或模块只讲一件事，只有一个视觉主体。大部分面积留给底色或空白，能删的元素都删掉。宁可少一点，也不要满。
2. **颜色少而稳**：单个画面最多三种颜色，即一个底色、近黑的线条、米白的色块。整页可以出现多个底色，但每个模块只用一个。鲜的颜色不能深，深的颜色要偏灰，不出现又深又艳的颜色。颜色要像颜料、陶土和纸，不能像屏幕发出的光。
3. **有分寸的手绘**：线条像粗马克笔画的，粗细略有变化，略微发抖；色块边缘略歪，像剪纸。但形状之间要对准，线条末端要落在该落的位置。粗糙但不潦草。
4. **一图一动作，日常物件做隐喻**：把抽象概念翻译成日常叫得出名字的物件，例如安全用锁，增长用树或台阶，连接用节点和线，思考用侧脸剪影，学习用打开的书。只画最简单的轮廓。AI 主题不画机器人，可以画人的侧脸加几个连成线的节点；网页主题不画电脑，可以画几个模块像积木一样搭起来。只用一个动作表达意思。第二层含义嵌进主物件内部，不要两个图标并排。
5. **人在场**：画面要让人感觉背后有一个人在做决定，而不是机器批量生成。手绘语言里，优先画一只手在和物件互动；摄影里，画面里要有真实的人或人留下的痕迹。

## 四、具体规则

### 配色（示例色值，可整体替换成同一逻辑的其他颜色）

- 底色任选其一：陶土橙 `#C96F4F`、橄榄绿 `#7D8B63`、雾蓝 `#6E97BF`、灰紫 `#C8C6D8`、仙人掌青 `#B9CEC6`、浅珊瑚 `#E8CBC8`、无花果紫红 `#B86580`、燕麦色 `#E2D9CB`
- 线条和深色背景：近黑 `#161615`
- 浅色背景和色块：米白 `#F7F5EF`，以及略深一档的 `#EEEBE3` 和 `#E6E3D9`，用来区分页面背景、卡片和分隔
- 灰色一律偏暖，从米白到近黑做成一组暖灰，不用冷灰和纯灰
- 深色方案和浅色方案同样常用：深色区块用近黑底，文字和线条改用米白，强调色只用陶土橙一种
- 一个画面只选一个底色，选定后不要随意改色或加色。多张图组成系列时，轮换底色，其余规则不变。

### 点缀色块（可选）

为了平衡构图，可以加 2 到 4 个很小的色块：手绘圆、小矩形或纸片形状。合计不超过画面面积的 5%，位置错落，不要均匀排列，不要像按钮，不要变成散点。

### 线条和形状

- 粗马克笔墨线，粗细略有变化，带轻微抖动，端点圆润
- 形状不是软件里的标准几何，圆不必正圆，方不必正方
- 线条要克制，但不必刻意少到只剩一两笔；表达节点网络、多只手等内容时可以多一些
- 插画最好做成透明底，同一张图可以放在不同底色上使用
- 不画阴影、高光、描边光晕和纹理堆叠；手绘语言最多加一层很淡的纸张颗粒，拼贴语言可以保留旧纸和印刷的质感

### 构图

主体居中或略偏，四周留出大量空白，不画背景场景。同一系列反复使用同一组物件（手、锁、书、树、节点、气泡、灯泡、纸张、台阶），重复带来辨识度。

### 文字和排版

- 字体分三类，最好来自同一个字体家族：衬线体用于大标题和长文标题（思源宋体、Georgia）；无衬线体用于界面、导航、正文和按钮，用得最多（Inter）；等宽字体用于代码、数据和标注（JetBrains Mono）
- 字号层级少，行距宽松，段落之间留白多，像一本书，不像一个仪表盘
- 浅色背景配近黑文字，深色背景配米白文字，强调色只用一个，而且用得很少
- 单张封面有标题时，标题是视觉中心，插画退到一侧做辅助；只放主标题，最多加一行副标题；不加栏目标签、Logo、日期、页码、品牌署名和没有意义的英文装饰字
- 网页里的卡片和列表可以有日期、分类和小图标，用小号浅灰字，放在标题下方或卡片底部

### 卡片和网格（网页、博客、文章列表）

卡片上半部分是彩色底的插画，下半部分是米白或浅暖灰的文字区，放衬线标题、一行摘要和日期分类。卡片圆角适中，没有阴影或只有极淡的阴影，用底色深浅区分层级。排成两列或三列网格，间距宽，相邻卡片轮换不同底色。

### 界面和动效（网页、App）

- 按钮和卡片是实心纯色或细线框，圆角适中，不用玻璃拟态、发光和渐变
- 动效短而轻：淡入、轻微位移，像翻纸，不弹跳、不闪烁
- 标志或图标可以用缓慢、有机的变形表示加载或思考的状态
- 插画用作点缀，一个区块最多一张

### 摄影（品牌、海报、视频）

真实的人和真实的工作环境，例如堆满书和纸的书房、实验室、户外自然。暖色自然光，色彩偏柔和，有轻微的胶片颗粒，像纪录片或档案照片。不用棚拍的科技感画面，不用屏幕光打脸，不用摆拍的商务人物。

### 文案语气

简短、准确、松弛，不喊口号，不用感叹号堆情绪。

## 五、按载体套用

- **插画、封面、海报**：纯色底 + 一个物件 + 一个动作，优先有一只手；横幅也只放一个主体；有标题时标题居中心，插画做辅助
- **品牌主视觉、研究报告头图**：用研究档案拼贴，旧照片和纸张为底，叠一两块纯色几何形状
- **网页、App**：米白和近黑两种区块交替，无衬线正文、衬线标题、大量留白；卡片网格按上面的规则；强调色只出现在一两个关键位置
- **图标**：实心底色块 + 米白或近黑的单一符号，线条略带手绘感
- **PPT、信息图**：一页一个观点；数据图只用底色 + 近黑 + 一个强调色，多组数据时从配色表里依次取色；不用 3D 图表
- **动效、视频**：线条逐笔画出，色块像纸片落下，节奏慢；实拍部分按摄影规则；不用粒子和光效

## 六、禁止清单

渐变（尤其是蓝紫渐变和彩虹渐变）、霓虹、发光、玻璃拟态、3D 渲染、金属质感、强阴影、高饱和的深色、冷灰、科技蓝、赛博朋克、电路板、发光大脑、机器人、粒子特效、密集装饰、多个主体并排、复杂信息图、画面里塞满文字、商业模板感、棚拍的科技感人像。

## 七、交付前自检

1. 删掉任何一个元素，画面会不会更好？会，就删。
2. 单个画面是否超过三种颜色？是否出现又深又艳的颜色？灰色是不是暖的？
3. 线条是否有手绘感，同时形状对得准？
4. 能否用一句话说出这个画面在讲什么？
5. 看起来更像一本书、一张纸、一份档案，还是一块发光的屏幕？必须是前者。
