2026-10-05 用户要求（先在母婴护理落地，"其他功能模块在软件中的显示，后期都是这个思路"）：
- 一线/管理人员**日常最常用的功能或记录页面按顺序放最前面**；
- 偏**后台设置/配置类**的页面（字段、项目、方案、模板、基础资料…）**合并成同一个管理入口**（页面内用标签页切换），放最后；
- 相关内容归并：护理档案的各部分都归到"母婴档案"详情页的标签页下，不在菜单里单列。

**已落地**：母婴护理菜单 = 护理看板 → 母婴档案 → 待跟进关怀 → 护理设置（`/care/settings`，标签：护理字段/护理项目/护理方案/关怀模板；旧地址 `/care/fields` 等已重定向）。导航项权限支持数组（任一权限即显示，`nav-menu.ts` 的 `perm: string | string[]`）。
**Why:** 菜单项太多、管理类页面日常用不到却占位置。
**How to apply:** 新做/改动任何模块时，先按此思路排菜单；其他模块（月子餐、产康、库存、人事、住店运营等）的整理已记入 `docs/待完善清单.md` E5，轮到时逐个做。关联 [[banyuexuan-care-archive-design]]、[[banyuexuan-todo-list-rule]]。
