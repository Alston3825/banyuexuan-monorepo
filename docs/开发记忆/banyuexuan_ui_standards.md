2026-10-15 用户要求把“当数据库某些项目数值较多，应主动加上搜索功能，实现快速定位”纳入软件编写规范，已落到仓库根目录 `CLAUDE.md`《界面开发规范》（之后每次会话自动加载）。2026-10-15 又加一条：所有页面设计和改动都要兼顾电脑端和手机端操作便利性，避免频繁/长距离横向滑动（手机用卡片列表、表单自动换行、375px 自测）。同文件还记了：表单弹窗不能点遮罩关闭、下拉数据不依赖管理权限、领用类录入先显示库存并拦截超量、列表默认要有内容、`await ctx.hasPermission`、删除走回收站、e2e 用独立库等。

**Why**：用户反复遇到“没有搜索，找不到某个员工/物品”“误点灰色区域丢失已填内容”“库存查询一片空白”这类问题，希望我主动避免而不是等他提。
**How to apply**：写任何新列表/下拉前先对照 CLAUDE.md；超过约 50 条的列表主动加搜索；未做的列表登记在 docs/待完善清单.md 的 U1。关联 [[banyuexuan-working-style]] [[banyuexuan-todo-list-rule]]。
