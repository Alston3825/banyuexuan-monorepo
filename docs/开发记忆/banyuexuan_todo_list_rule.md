2026-10-05 用户明确要求："从现在开始，把现在没有数据或者暂时空置的链接都汇总记录起来，包括我说的所有后面再完善的数据或页面内容，以便后期不会遗漏。"

**Why:** 项目功能多、分期做，用户怕占位页面/按钮/数据后面被忘掉。
**How to apply:** 文件在仓库 `docs/待完善清单.md`（已建，含护理/客户/合同/环境四类）。每次新增占位按钮、空数据文字、"以后再做/先不做"的决定，**当场追加一行**；做完改状态写日期，不删行。每次回复末尾若有新增占位，顺带提一句"已记入待完善清单"。关联 [[banyuexuan-care-archive-design]]、[[banyuexuan-working-style]]。
