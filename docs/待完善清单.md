- 对比标准：WS/T 423—2022《7岁以下儿童生长标准》百分位表，只收录 0～36 月龄；头围用 0～3 岁标准。
- 早产儿（孕周 <37 周）按矫正月龄；目前孕周没有独立字段，依赖宝宝档案已有孕周信息。
- 百分位是在 P3/P10/P25/P50/P75/P90/P97 之间线性插值估算；以后可换成 Z 评分（LMS/SD）法。
- 客户链接 90 天有效、重新生成会让旧链接作废；手机页图上文字偏小，可考虑手机端单独出竖版大字图。
